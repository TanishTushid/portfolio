## 🧠 Deep Learning Lab

### A hands-on collection of Deep Learning experiments, notes & projects

A continuously evolving repository documenting my journey through **Deep Learning**, from neural-network fundamentals to CNNs, RNNs, LSTMs, GRUs, NLP, and modern architectures.

Rather than focusing only on finished applications, this repository captures the **learning and experimentation process** through Jupyter notebooks, implementations, notes, model training experiments, and practical projects.

---

### 🔬 What I've Explored

**Neural Networks**

* Perceptron & ANN
* Forward & Backpropagation
* Activation & Loss Functions
* Optimizers
* Regularization & Dropout

**Computer Vision**

* CNN
* Image Classification
* Data Augmentation
* Transfer Learning
* LeNet • AlexNet • VGG • GoogLeNet
* ResNet • DenseNet • EfficientNet

**Sequence Models**

* RNN
* LSTM
* GRU
* Sequence Prediction
* Vanishing Gradient Problem

**NLP**

* Text Preprocessing
* Tokenization
* Embeddings
* Next Word Prediction
* Sentiment Analysis
